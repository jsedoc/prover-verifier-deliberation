# Learning to abstain in extractive question answering
Haruto Ito, Sofia Brandt. 2020. Findings of the Conference on Fictional NLP.
(Fictional source written for the prover-verifier-paper evaluation fixture.)

## Abstract
We add an [ABSTAIN] token to the output vocabulary of an extractive question answering model and train
it with a reject-option loss, so that the model can decline to answer when its predicted span is likely
to be wrong. On two reading-comprehension benchmarks the abstain token improves accuracy on answered
questions at fixed coverage.
