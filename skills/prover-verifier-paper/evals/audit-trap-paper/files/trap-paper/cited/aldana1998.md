# Optimal rejection rules for classifiers with a reject option
Rosa Aldana. 1998. Journal of Pattern Decisions 12(3):45-61.
(Fictional source written for the prover-verifier-paper evaluation fixture.)

## Abstract
A classifier that may reject (abstain on) inputs can trade coverage for accuracy: rejecting more inputs
lowers the error rate on the inputs it accepts. We derive the optimal rejection threshold for a given
cost of rejection.
