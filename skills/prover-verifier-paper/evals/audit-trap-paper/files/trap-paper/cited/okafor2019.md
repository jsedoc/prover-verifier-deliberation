# On measuring calibration error
Chidi Okafor. 2019. Transactions on Imaginary Machine Learning.
(Fictional source written for the prover-verifier-paper evaluation fixture.)

## Abstract
Expected calibration error (ECE) has become the most widely reported calibration metric for neural
classifiers. We show that ECE estimates vary substantially with the number of bins used to compute
them, and that rankings of models by ECE can flip when the binning scheme changes.
